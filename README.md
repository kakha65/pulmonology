# პულმონოლოგია | Pulmonology

GitHub Pages-ready landing page for the internal medicine digital textbook.

## გამოქვეყნება

1. შექმენით `pulmonology` რეპოზიტორია GitHub-ზე (`kakha65`), აირჩიეთ Public.
2. ატვირთეთ ZIP-ის შიგთავსი რეპოზიტორიის ძირეულ საქაღალდეში (არა გარე საქაღალდეში).
3. Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.
4. გამოქვეყნების შემდეგ მისამართი იქნება https://kakha65.github.io/pulmonology/ .

## სტრუქტურა

- `index.html` — თემების კატალოგი (11 თემა).
- `style.css` — ადაპტიური დიზაინი და A4 ბეჭდვა.
- `script.js` — ქართულ/ინგლისურ საძიებო სისტემას, Ctrl/Cmd+K და შედეგების მრიცხველს მართავს.
- `assets/` — SVG ემბლემა და ფილტვების ვექტორული ფონი.
- `chapters/<slug>/index.html` — თითოეული თავის საწყისი გვერდი; ჩაანაცვლეთ შესაბამისი დასრულებული სახელმძღვანელოთი.
